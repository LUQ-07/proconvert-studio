# Code of conduct

This project is meant to be a friendly place to learn and build. By taking part you agree to:

* be respectful and patient, especially with beginners;
* give and accept feedback about the work, not about the person;
* not harass, insult or discriminate against anyone, and not share other people's private information;
* assume good intentions and ask when something is unclear.

Maintainers may edit, hide or remove comments, issues and pull requests that break these rules, and may block people who
repeat the behaviour. To report a problem, contact the maintainer privately through the e-mail or profile shown on the
maintainer's GitHub page.
