# Privacy

ProConvert Studio is a local program. In short: **it does not collect, send or share any data.**

* **Your documents** are read from the place you choose and the result is written to the place you choose. They are never
  uploaded. The original file is never modified.
* **No network.** The application does not contact any server: no analytics, no telemetry, no advertising, no update check.
  (To update, download a new release yourself.)
* **What is stored on your computer** (in your user profile folders, not next to your documents): your settings, a conversion
  history (file names, formats, status and duration; you can search, clear it or limit how long it is kept), and a log file with
  technical messages. Log lines are filtered so that document content and passwords are not written to them.
* **Diagnostics export** (Settings > Advanced) creates a zip file **only when you press the button**. It contains version and
  system information and the log, never document content. It is saved where you choose; nothing is sent automatically, you decide
  whether to attach it to a bug report.
* **OCR** (optional) runs locally with Tesseract. Pictures and scanned pages stay on your computer.

If this ever changes (for example an optional online feature), it will be opt-in, documented here and in the release notes.
